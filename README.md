# Inkline

An Obsidian plugin for drawing small symbols that sit inside a line of text
like characters: invented scripts and conlang glyphs, puzzle and game marks,
personal shorthand, and notation that no font has.

Each symbol is a normal PNG file in your vault, embedded with a normal image
link, so your notes still show it if you disable or uninstall the plugin.

## Status

Under development, with no release yet. This repository is a rewrite of an
earlier prototype; the rewrite changes the file format, the editor, and how
symbols are rendered, and keeps the prototype's files readable.

Inkline is written and maintained by AI agents, and no person reviews the
code. Changes are accepted on their unit tests, on end-to-end tests that run
the plugin in real Obsidian builds, and on an independent review by an agent
from a different model provider than the one that wrote the change.
[AGENTS.md](AGENTS.md) holds the agents' rules for this repository.
